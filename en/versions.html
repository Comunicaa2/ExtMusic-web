2Install

  1. On your phone, download ExtMusic-1.4.2.apk from GitHub.
  2. Open it. The first time, Android will ask you to allow your browser (or file manager) to install apps: turn it on and go back.
  3. Tap Install. You need Android 8.0 or later.

What the app asks for when you start: Docs → Getting started.

After that you don't need to come back here: the GitHub version checks for updates (in Ajustes → Buscar actualizaciones, Settings → Check for updates, or by itself when you open it, at most once a day), downloads the new one, checks it and opens the Android installer for you to confirm.

3Check the file

This is optional. It makes sure the APK is exactly the published one and that it is signed with the ExtMusic key.

  1. File fingerprint. Compute it and compare it with the SHA-256 in Table 1 (or the one for its version in the history):
    sha256sum ExtMusic-1.4.2.apk
  2. Signature. With apksigner (included in the Android SDK build tools):
    apksigner verify --print-certs ExtMusic-1.4.2.apk
    The certificate's SHA-256 fingerprint must be:
    7492411a3df91a2128010740826791eed78f15deba2a962bea2ca6e9e2a3e2a7
